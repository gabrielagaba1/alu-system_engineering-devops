# SSH

This project covers SSH connections and remote server authentication.

## 0. Use a private key

The `0-use_a_private_key` Bash script connects to a remote server
using the private key located at `~/.ssh/school` and the `ubuntu` user.

## Requirements

- Ubuntu 20.04 LTS
- Bash scripts must start with `#!/usr/bin/env bash`
- The second line must explain the script's purpose
- All Bash scripts must be executable
- Files must end with a newline
