# 0x0B. SSH

## Description
This project covers SSH configuration and secure connections to remote servers using private keys.

## Tasks

### 0. Use a private key
The `0-use_a_private_key` script connects to a server using SSH, the private key located at `~/.ssh/school`, and the `ubuntu` user.

## Requirements
- Scripts run on Ubuntu 20.04 LTS.
- Bash scripts begin with `#!/usr/bin/env bash`.
- The second line of every Bash script explains its purpose.
- All Bash scripts are executable.
- All files end with a newline.
